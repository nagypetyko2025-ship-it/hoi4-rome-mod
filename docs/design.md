# Ante Imperium – design

## Start dates (AUC)
1. Early Rome as a city-state: 245 AUC (509 BC, Republic founded) or 411 AUC (343 BC, Samnite wars) – NOT DECIDED.
2. Rome master of peninsular Italy: 490 AUC (264 BC, First Punic War).
HoI4 games span ~10–20 years, so the two starts are separate scenarios.

## Map
Keep vanilla province map; redraw states, strategic regions, supply. Playable: Europe, North Africa, western Near East. Rest = wasteland.

## Systems to replace
- Tech tree: metalworking, phalanx/maniple, siegecraft, roads, aqueducts, ships (trireme, quinquereme).
- Units: hoplite, peltast, hastati/principes/triarii, warband, slinger, archer, cavalry, chariot, war elephant.
- Equipment: weapons, shields/armour, horses, elephants. Industry: workshops/forges/shipyards.
- Resources: iron, copper, tin, timber, horses, grain (TBD vs engine limits).
- Ideologies: republic, monarchy, tyranny, tribal confederation.
- Remove/hide air, nukes, radar, modern systems. Unit display: NATO counters.

## Phases
0. Foundation: mod folder, git, date engine test  (DONE: 245.1.1.12 loads; history runs from -1.1.1.1, vanilla history before 245 is applied)
1. Skeleton: states, countries, empty out modern content
2. Tech/units/equipment
3. Rome + neighbours fully playable (start date 1)
4. Other peoples and focus trees
5. Second start date (490 AUC)
6. AI, balance, graphics, localisation
